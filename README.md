# BEHIND THE RAIN — AU Chapter 2
## The Face I Thought I Knew

Chapter 2 is based on the structure and composition of `BehindTheRain-AU-Chapter1`, not the main Behind the Rain website.

- Same C1-style signature intro, welcome screen, wide narration card, social cards, progress bar, Previous/Next navigation, ending screen and Liquid Glass player.
- Intro retains the C1 layout and animation; chapter label changes to CHAPTER 2 and the title gradient/glow changes to warm orange and white.
- Story theme: sunset nostalgia, diffused sun glow, dark tree silhouette at the right, ground at the bottom, wind and falling leaves. No rain and no dominant blue.
- Five manual audio slots: add `song-01.mp3` through `song-05.mp3` inside `assets/music/`; set titles and artists in `script.js`.
- Some dialogue/social posts that were not remembered verbatim are creative reconstructions, not exact transcripts.

To publish, upload the project files to a new repository and enable GitHub Pages from `main` / root.
